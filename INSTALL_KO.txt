wsflow 워크플로우 - 내 PC(Windows)에 적용하는 방법
==================================================

이 repo(sumin-git6321/devenv)는 kang-sw/devenv를 복사한 것입니다.
Claude Code에 "wsflow" 플러그인으로 설치해서 사용합니다.


1. 사전 준비
------------

필요한 프로그램
  - Claude Code      : 설치 및 로그인 완료 상태
  - Git              : git --version 으로 확인
  - Python 3         : wsflow MCP 서버가 python3 로 실행됩니다 (필수)
  - GitHub CLI (gh)  : 선택. repo 수정/푸시할 때만 필요

Python 설치 (Scoop 사용 시)
  > scoop install python
  > python3 --version

  * "python3" 명령이 없다고 나오면 MCP 서버가 뜨지 않습니다.
    (증상: Claude Code 시작 시 plugin:wsflow:wsflow CONNECTION_CLOSED)
  * python.org 설치본을 쓰는 경우, 설치 시 "Add python.exe to PATH"를
    체크하고, python3 명령이 없으면 Scoop 설치를 권장합니다.


2. 플러그인 설치
----------------

PowerShell 또는 터미널에서 실행합니다.

  > claude plugin marketplace add sumin-git6321/devenv
  > claude plugin install wsflow@kang-sw-devenv

  * 마켓플레이스 이름은 repo 안의 .claude-plugin/marketplace.json 에
    "kang-sw-devenv" 로 되어 있어서, 설치 명령의 @ 뒤도 kang-sw-devenv 입니다.

  * 이미 원본(kang-sw/devenv) 마켓플레이스가 등록되어 있으면 이름이 겹칩니다.
    먼저 아래처럼 제거한 뒤 위 명령을 실행하세요.

      > claude plugin uninstall wsflow@kang-sw-devenv
      > claude plugin marketplace remove kang-sw-devenv

설치 확인
  > claude plugin list
    -> wsflow@kang-sw-devenv / Status: enabled 이면 정상

설치 후 Claude Code를 재시작합니다.
첫 실행 때 런처가 ws-mcp 실행 파일을 자동으로 내려받습니다
(다운로드 위치: kang-sw/devenv 의 GitHub Release).


3. 동작 확인
------------

Claude Code 안에서
  - /mcp 를 입력해 "wsflow" 서버가 connected 인지 확인
  - 스킬 목록에 wsflow:lead-discuss, wsflow:lead-run, wsflow:lead-ticket
    등이 보이면 정상


4. 프로젝트에 적용 (프로젝트마다 1회)
-------------------------------------

워크플로우를 쓰려는 프로젝트 폴더(git repo)에서 Claude Code를 열고

  /wsflow:lead-bootstrap

를 실행합니다. 프로젝트에 다음이 만들어집니다.
  - AGENTS.md            : 에이전트용 프로젝트 안내
  - CLAUDE.md            : @AGENTS.md 한 줄 (Claude 호환용)
  - ai-docs/             : tickets/, manuals/, WORKFLOW.md 등

기본 사용 흐름
  /wsflow:lead-discuss   방향/설계 논의 (코드 수정 없음)
  /wsflow:lead-ticket    결정된 내용을 티켓으로 작성 -> ready/ 승격
  /wsflow:lead-run       ready 티켓 실행 (구현, 검증, 리뷰, 커밋)
  /wsflow:lead-delegate  작고 되돌릴 수 있는 작업을 바로 맡기기
  /wsflow:lead-review    PR/브랜치 리뷰


5. 업데이트
-----------

(1) 원본 업데이트를 내 repo로 가져오기 (이 repo 폴더에서)
  > git pull upstream main
  > git push origin main

  * upstream 이 없으면 한 번만 등록:
    > git remote add upstream https://github.com/kang-sw/devenv.git

(2) PC에 설치된 플러그인 갱신
  > claude plugin marketplace update kang-sw-devenv
  > claude plugin update wsflow@kang-sw-devenv
  그 후 Claude Code 재시작


6. 문제 해결
------------

[MCP 서버 연결 실패 (CONNECTION_CLOSED)]
  - python3 --version 이 동작하는지 확인 (1번 항목)
  - 회사망 등에서 GitHub Release 다운로드가 막히면 런처가 실패할 수 있음

[git push 시 403 (Permission denied to 다른계정)]
  - Windows 자격 증명 관리자에 다른 GitHub 계정이 저장된 경우입니다.
  - gh 로그인 계정을 git 인증에 쓰도록 설정:
    > gh auth login
    > gh auth setup-git

[push 시 "without workflow scope" 거부]
  - .github/workflows 파일을 올리려면 workflow 권한이 필요합니다.
    > gh auth refresh -h github.com -s workflow

[gh auth login 이 Claude Code 프롬프트에서 멈춤]
  - 대화형 명령이라 별도 PowerShell 창에서 실행하는 것이 편합니다.
